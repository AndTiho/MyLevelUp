# MyLevelUp
** Бэкенд-часть SPA веб-приложения "Трекера полезных привычек".
## Описание
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/RESTstudy.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование

## Запуск и ожидаемое поведение программы
Для запуска проекта воспользуйтесь:
```
python manage.py runserver
```

Программа находится на стадии разработки.
