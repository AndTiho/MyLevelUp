# MyLevelUp
** Бэкенд-часть SPA веб-приложения "Трекера полезных привычек".
## Описание
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/MyLevelUp.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование

## Запуск и ожидаемое поведение программы
Для запуска проекта воспользуйтесь:
```
python manage.py runserver
```

Программа находится на стадии разработки.


## Документация:
Для получения дополнительной информации, вы можете воспользоваться возможностью
чтения файла [Список зависимостей](requirements.txt)

## Документация API

После запуска сервера документация доступна по ссылке:
- [Swagger](http://localhost:8000/swagger/)
- [ReDoc](http://localhost:8000/redoc/)

В данный момент проект распространяется без лицензии.
